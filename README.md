# Weather dashboard (Open-Meteo) scaffold

This is a small Next.js + Tailwind CSS demo that fetches weather data from Open‑Meteo (no API key required).

Run locally:

1. npm install
2. npm run dev
3. Open http://localhost:3000

What I built:
- Search by city name (uses Open‑Meteo geocoding)
- Detect device location (geolocation)
- Current weather, hourly (24h) and 7-day daily summary

Notes:
- This scaffold is added to the big-boy-games repository as requested.
- To deploy to Vercel: connect the repo and deploy — no env vars required.
